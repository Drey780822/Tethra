## 🎯 Purpose

Tethra is built around a simple workflow:

<p align="center">
  <strong>TARGET → PRIORITISE → DO → COMPLETE</strong>
</p>

Users can quickly create individual or bulk tasks, organise them by time and priority, attach relevant documentation, and track their progress from one simple workspace.

## ✨ Core features

- 📝 Simple task creation and management
- 📋 Bulk task creation
- 🎯 Time-based task targeting
- 🔴 Task prioritisation
- 📎 Documentation and file attachments
- ✅ Task completion tracking
- 📊 Personal productivity board
- 📧 Completion notifications
- 📱 Fully responsive, mobile-first experience
- 🎨 Modern, minimal interface

## Philosophy

> Tethra is designed to feel less like a complicated productivity suite and more like walking into an empty classroom and using the whiteboard to plan what needs to get done.

## 🌍 Open source

Tethra is open-source and built to be simple, accessible, and useful for anyone who wants a focused way to manage their work.

Contributions, ideas, improvements, and feedback are welcome.
